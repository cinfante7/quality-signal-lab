# Quality Signal Lab

A small, inspectable quality-engineering and applied-machine-learning portfolio
demonstration for Christopher Infante. **New AI-assisted project created October
2026.** This is not a historical professional accomplishment or graduate capstone.

Compare fixed inspection limits with a trained logistic classifier on generated
scalar measurements. Begin with requirements, data integrity and an honest batch
holdout; end with errors and the operational consequences of the decision policy.
All code is original to this project and all data is generated here.

## Start in two commands

Python 3.10+; verified locally with Python 3.13.7. No dependencies, install step,
paid API, hosted service, credentials or global configuration changes.

From this directory:

```powershell
python verify.py
python quality_lab.py --output artifacts
```

Open [the local HTML report](artifacts/report.html) in a browser, or read
[the Markdown evaluation](artifacts/report.md). The command overwrites only
generated files in the chosen output directory; choose a project-local directory.
To run the tests without writing logs: `python -m unittest -v`.

## Actual first-release evaluation

2,400 synthetic items; 1,400 training / 400 validation / 600 held-out test.
Entire batches 10–12 stay out of training and threshold selection. The test
contains 237 invented defects. Positive prediction means flag for review.

| Held-out measure | Fixed rule | Logistic model |
|---|---:|---:|
| True negatives | 281 | 71 |
| False alarms | 82 | 292 |
| Missed defects | 132 | 10 |
| Detected defects | 105 | 227 |
| Precision | 56.1% | 43.7% |
| Recall | 44.3% | 95.8% |
| Accuracy | 64.3% | 49.7% |
| Assumed cost: 5 × missed defects + false alarms | 742 | 342 |
| Items flagged for review | 31.2% | 86.5% |

**ML is not an unconditional improvement.** At equal error costs, the fixed rule
has fewer errors (214 vs 302). Under the illustrative 5:1 penalty, ML has lower
cost, but simply flagging everything costs 363, only 21 more than ML.
A model flagging 86.5% of items may overwhelm an inspection queue.
The threshold 0.20 was selected from a fixed validation-only grid; it was not
tuned against these test results. No assertion requires ML to beat the rule.

## Design and limits

The transparent baseline uses invented diameter, surface and vibration limits.
The model uses absolute deviation from nominal diameter plus surface and
vibration; sample IDs, batches and labels are excluded from its inputs.
Training fits its standardization and coefficients. Later validation batches
choose the decision threshold; still later batches provide the final comparison.

The label generator uses additive logistic risk with Bernoulli noise and gradual
drift. That mechanism resembles the model, so any advantage partly reflects the
synthetic assumptions. A single seed does not represent a population of factories.
This is not machine vision, measurement-system validation, a quality certification,
or evidence of real manufacturing performance. No company branding, confidential
data, patient data, borrowed assets or security tooling is included.

Before a real deployment: establish measurement repeatability and reproducibility,
review independent adjudicated labels and lots, quantify escape severity and
review capacity, test unseen failure modes, and retain human disposition decisions.

## Revision 2: customer specification and capacity review

[Revision 2 report](refinement/report.html) provides a clear **NO-GO** decision.
This refinement was designed after viewing the first report, and preserves it.
The model, scaling and rule are frozen. Policy thresholds use only the original
validation batches; newly generated later batches 13–15 provide a new 600-item
holdout, with no subsequent threshold tuning.

The [fictional customer specification](CUSTOMER-SPEC.md) defines mandatory
measurement flags, at most 80 review items per 200-item batch, and at least 80%
latent-defect recall. No validation threshold met both requirements.
The capacity-selected hybrid threshold 0.40 achieved 78.0% recall and flagged
59.7% on the new holdout; it misses 58 defects and produces 152 false alarms.
The fixed rule flags 42.3%; original cost-only ML flags 92.3%. None qualifies.

[Process map](PROCESS-MAP.md) and [prioritized issue log](ISSUE-LOG.md) connect
specification interpretation, data checks, queue capacity and investigation.
A descriptive batch-variation summary and mutually exclusive prediction-error
Pareto demonstrate introductory quality-method reasoning. No stable-process
capability, Six Sigma certification, factory experience, optical hardware
experience or real customer outcome is claimed.
